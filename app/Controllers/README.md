# 💖 Aplikasi

DevithaShop merupakan aplikasi e-commerce sederhana berbasis web menggunakan Framework CodeIgniter 4 dan Public API.

Fitur aplikasi:
- Menampilkan produk dari API
- Search produk
- Cart / keranjang belanja
- Checkout pesanan
- Penyimpanan data ke database MySQL
- Menampilkan data pesanan

---

# ⚙️ Teknologi

- CodeIgniter 4
- PHP
- MySQL
- JavaScript
- HTML & CSS
- FakeStore API
